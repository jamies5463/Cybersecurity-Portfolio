# Jamie Satterley - Exeter, UK - jamiesatterley@hotmail.com - Cybersecurity Portfolio

## About
I work in digital systems and IT support, where my day-to-day tasks include designing and maintaining a database platform, managing user accounts and access, supporting mobile device management, and improving the processes behind them. I came to this from a social work background, and I am developing my technical knowledge alongside the job.

I chose the Google Cybersecurity Certificate for its breadth: networks, firewalls, risk management, Linux, SQL and incident response all connect directly to the systems I work with. This portfolio records what I have learned as I go, so some pieces are more developed than others.

All incidents, organisations and people described here are fictional and based on course scenarios, unless a piece states otherwise.

## Portfolio pieces

1. [Home network and password security audit](01-home-security-audit.md) - an audit of my own home network, password practices and IoT devices against NCSC and NICSC guidance, with a controls assessment, mitigation plan and review.
2. [Responding to a brute force attack](02-responding-to-brute-force-attack.md) - incident report on a compromised website admin panel, using tcpdump and sandbox analysis.
3. [Reading a Wireshark log](03-responding-to-attack-reading-wireshark-log.md) - incident report analysing a Wireshark capture to identify a SYN flood (DoS) attack on a company website, explaining how it exploits the TCP handshake and the response taken.
4. [tcpdump analysis](04-tcpdump-analysis.md) - Incident report using tcpdump to diagnose a website outage (“udp port 53 unreachable”), tracing it to a DNS server fault and suggesting a DoS attack or firewall misconfiguration as likely causes.
5. [Data breach investigation](05-data-breach-investigation.md) - Risk assessment of a social media data breach, identifying four vulnerabilities and recommending hardening measures such as MFA, network segmentation and WPA3.
6. [ICMP flood incident report](06-ICMP-attack-response.md) - a DoS incident analysed using the NIST Cybersecurity Framework.
7. [Managing file permissions in Linux](07-using-linux-commands-to-manage-file-permissions.md) - Linux file permissions walkthrough using ls -la and chmod (symbolic and numeric) to inspect and change file, hidden file and directory permissions, with explanations of the permissions string.
